# ADR-0003：遮罩是"视觉级"而非"安全级"

- 状态：Accepted

## 背景

答案遮罩想达到"浏览笔记时答案默认不可见，点击才显示"。存在两种实现强度：

- 视觉级：CSS 遮罩（blur/覆盖层），答案文本仍在 DOM 中；
- 安全级：渲染前就把答案排除出 DOM，需要时再从内存/文件取回。

## 决策

- **阅读视图（就地模糊）用视觉级 CSS 遮罩**：`filter: blur()` / 白色覆盖层 + `user-select:none`，并关闭图片拖拽。
- 明确接受"DevTools 里能看到答案文本"这一限制——本地笔记场景威胁模型是"防止自己无意扫到 / 防止误看剧透"，不是防黑客。
- 同时关掉选择/复制与图片拖拽，防止**手滑把答案拖拽或复制出去**这类真实高频误操作。

## 代价与后续

- 视觉级遮罩的"强度"受限于 CSS 可表达范围（blur 后的文字轮廓仍隐约可辨）。
- 产品上对防偷看的更硬诉求出现在**复习会话（M2）**：那时答案由插件视图自己渲染，可以先不放入 DOM、点击揭晓才注入 → 达到"安全级"而无需妥协。
